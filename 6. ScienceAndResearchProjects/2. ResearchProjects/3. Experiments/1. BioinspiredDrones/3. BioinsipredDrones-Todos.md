# Autonomous bioinspired drones: Plan



1. Describe the paper - "Computational exposition of multistable rhythms in 4-cell neural circuits - Krishna Pusuluri, Sunitha Basodi, Andrey Shilnikov; 2020; CNSNS;"  at the level of an advanced 8 year old student who understands programming. Think about the mathematical equations and analysis results for different CPG rhythms as function parameters that you can use to produce different CPG rhythms. Explain all the details of neurons, models, CPGs, rhythms, pacemakers, traveling waves, phase shifts etc. in a way the kid can understand. And how he can understand each of the paper figures in detail so he can use them later to simulate different rhythms.

2. The goal is to integrate 4 cell CPGs with Quadcopter drones, (eg. Crazyflie open drone systems), but for a start we want to do this with simulated drones. So we need a drone simulation in python. Should be able to control the virtual drones' fllight similar to how you would control a physical drone. 

3. Then let's integrate the 4 cell CPG code ([Bitbucket](https://bitbucket.org/pusuluri_krishna/cpg_multistability/src/master/4cellCircuits_CNSNSPaper/)) with the drones; We don't need the whole analysis from the bitbucket code. We only need to use the parameter combinations from the paper to generate different rhythms or traces ( tracesTest_4Cell.py ).  The four cells of CPG should be connected to the four propellors of the drone. The voltages of the cells should control the speeds of the propellors. So if the CPG is set for a paired halfcenter rhythm, two of the propellors increase their speed so the drone moves forwards then the other two propellors increase their speed while the first two decrease so the drone moves backwards. It will continue doing this rhythmic motion along with the CPG. Depending on the rhythm chosen for the CPG the drone can autonomously produce rhhythmic behaviors. We can also superimpose rhythms so for example the drone can move forwards in serpentine motion.
