# 🎮 Linux Terminal Gym: Set 2 (20 Extra Rep Exercises)

Set 2 went full hacker-mode pretty fast, so let's dial it back and get some **extra reps** on the core commands from the original guide and Set 1! 

This workbook uses **zero complicated new commands**—it's 100% focused on helping you build muscle memory with the essentials:

* **Navigation & Paths:** `pwd`, `ls`, `cd`, relative paths (`..`), and wildcards (`*`, `{}`)
* **File & Folder Ops:** `mkdir`, `touch`, `cp`, `mv`, `rm`, `rmdir`
* **Reading & Writing:** `echo`, `cat`, `head`, `tail`, `vim`, `>`, `>>`
* **Sorting, Searching & Counting:** `sort`, `uniq`, `grep`, `find`, `wc`
* **Combos & Permissions:** Pipes (`|`), chains (`&&`), `chmod`, `ssh`, and PowerShell basics

---

## 🛡️ Step 0: Spawn Your Safe Practice Arena

Open your terminal and run this single line to create a fresh, safe folder for this workout:

```bash
mkdir -p ~/practice_arena && cd ~/practice_arena
```

---

## Part 1: Folder Building, Paths, & File Spawning

### Exercise 1: The Music Library Setup (`mkdir -p` & `{}`)

* **Scenario:** You're organizing your music collection into folders by genre, and you want to build the whole folder tree in one shot.
* **Challenge:** Use `mkdir -p` and brace expansion `{}` to create a folder called `music` that contains three subfolders inside it: `rock`, `hiphop`, and `electronic`.

### Exercise 2: Chained Teleport & File Spawn (`&&` & `touch`)

* **Scenario:** You want to jump into your new `music/rock` folder, create three empty song files, and immediately check that they are there.
* **Challenge:** On a **single line** using `&&`, teleport (`cd`) into `music/rock`, use `touch` to create `song1.mp3`, `song2.mp3`, and `tracklist.txt`, and run `ls`. (When done, run `cd ~/practice_arena` to return to base).

### Exercise 3: Relative Path Hop (`cp` & `..`)

* **Scenario:** You are currently inside `music/rock`, and you realized `tracklist.txt` also needs a copy inside `music/hiphop`.
* **Challenge:** 
  1. `cd` into `music/rock`.
  2. Without leaving `music/rock`, use `cp` and the parent folder shortcut (`..`) to copy `tracklist.txt` into the `hiphop` folder and name the copy `hiphop_tracks.txt`.
  3. Teleport back to `~/practice_arena`.

### Exercise 4: Spotting Hidden Files by Time (`ls` flags)

* **Scenario:** Someone dropped a hidden file into your folder, and you want to see all files (including hidden ones) in a detailed list, sorted by **when they were last modified** (`-t` sorts by time, newest first!).
* **Challenge:** First run `touch .secret_key` to create a hidden file. Then run `ls` combining the long format (`-l`), all/hidden (`-a`), and time-sort (`-t`) flags.

## Part 2: Writing, Reading, & Combining Files (`echo`, `cat`, `head`, `tail`)

### Exercise 5: Building a Watchlist (`echo`, `>`, `>>`)

* **Scenario:** You want to make a quick list of anime/shows to watch without opening a text editor.
* **Challenge:** 
  1. Use `echo` and `>` to create `watchlist.txt` with the first line: `Attack on Titan`
  2. Use `echo` and `>>` three times to add `Naruto`, `One Piece`, and `Naruto` (yes, add `Naruto` twice!) on separate lines at the bottom of `watchlist.txt`.

### Exercise 6: Numbered Inspection (`cat -n`)

* **Scenario:** You want to check your `watchlist.txt` and see the exact line number next to each show.
* **Challenge:** Use `cat` with the line-numbering flag to display `watchlist.txt`.

### Exercise 7: Merging Two Lists (`cat` + `>`)

* **Scenario:** Your friend sends you their movie list, and you want to glue your `watchlist.txt` and their `movies.txt` together into one giant list.
* **Setup:** Run this first to create your friend's list:
  
  ```bash
  printf "Inception\nThe Matrix\nInterstellar\n" > movies.txt
  ```
* **Challenge:** Use `cat` to combine `watchlist.txt` and `movies.txt` and redirect (`>`) the combined result into a new file called `binge_list.txt`.

### Exercise 8: Peeking at the Top and Bottom (`head` & `tail`)

* **Scenario:** `binge_list.txt` has 7 items total, but you only want to see the very first 2 items, and then the very last 2 items.
* **Challenge:**
  1. Run `head` with the `-n` flag to display only the **first 2 lines** of `binge_list.txt`.
  2. Run `tail` with the `-n` flag to display only the **last 2 lines** of `binge_list.txt`.

## Part 3: Sorting, Deduplicating, & Counting (`sort`, `uniq`, `wc`, `|`)

### Exercise 9: Alphabetizing & Removing Duplicates (`sort` | `uniq`)

* **Scenario:** Remember how `"Naruto"` accidentally got added twice to `watchlist.txt`? Let's clean it up!
* **Challenge:** Pipe (`|`) `sort watchlist.txt` into `uniq` so it prints an alphabetical list with no duplicate shows, and redirect (`>`) that clean output into `clean_watchlist.txt`.

### Exercise 10: Counting How Many Times Each Show Appears (`uniq -c`)

* **Scenario:** Instead of just deleting duplicates, you want to see a count next to each show in `watchlist.txt` proving how many times it was listed.
* **Challenge:** Pipe `sort watchlist.txt` into `uniq -c` to see the vote count for each show!

### Exercise 11: High Score Leaderboard (`sort -nr` & `head`)

* **Scenario:** Your gaming squad just finished a tournament and recorded their kills in a text file.
* **Setup:** Run this first:
  
  ```bash
  printf "14 Shadow\n32 Viper\n7 NoobMaster\n45 Ghost\n19 Blaze\n" > squad_kills.txt
  ```
* **Challenge:** Use `sort` with the numeric (`-n`) and reverse (`-r`) flags on `squad_kills.txt`, and pipe (`|`) it into `head` to show **only the #1 top player** (top 1 line).

### Exercise 12: Counting Total Songs & Lines (`wc -l`)

* **Scenario:** You want to know the exact number of lines inside `binge_list.txt` without counting them yourself.
* **Challenge:** Run `wc` with the lines flag (`-l`) on `binge_list.txt`.

## Part 4: Searching Like a Detective (`grep` & `find`)

### Exercise 13: Finding Specific Players in Chat Logs (`grep -i`)

* **Scenario:** You have a chat log from a game server and want to find every line where someone mentioned `"dragon"`, whether they typed `"Dragon"`, `"DRAGON"`, or `"dragon"`.
* **Setup:** Run this first:
  
  ```bash
  printf "Player1: Watch out for the Dragon!\nPlayer2: Need healing\nPlayer3: DRAGON breath incoming!\nPlayer4: GG ez\nPlayer1: Where is the dragon?\n" > chat.log
  ```
* **Challenge:** Use `grep` with the case-insensitive flag (`-i`) and the line-number flag (`-n`) to find all mentions of `"dragon"` in `chat.log`.

### Exercise 14: Counting Match Results (`grep` | `wc -l`)

* **Scenario:** How many lines in `chat.log` were sent by `Player1`?
* **Challenge:** Use `grep "Player1" chat.log` and pipe (`|`) the output into `wc -l` to get the exact number of messages from `Player1`.

### Exercise 15: Hiding Annoying Messages (`grep -v`)

* **Scenario:** You want to read `chat.log`, but `Player1` talks too much and you want to mute all of their messages from your view.
* **Challenge:** Use `grep` with the invert-match flag (`-v`) to display every line in `chat.log` **except** lines containing `"Player1"`.

### Exercise 16: Locating All MP3 Files (`find`)

* **Scenario:** Earlier you created some `.mp3` files inside a subfolder of `music`, and now you want your terminal to track down every `.mp3` file anywhere inside `~/practice_arena`.
* **Challenge:** Use `find . -name` with a wildcard (`*`) to find all files ending in `.mp3`.

## Part 5: Wildcards, Cleanup, Scripts, & Windows Translation

### Exercise 17: Wildcard Backup Copy (`cp` + `*`)

* **Scenario:** You want to back up every single `.txt` file in your current folder into a new folder called `txt_backups` in one move.
* **Challenge:** Create a folder called `txt_backups`, and use `cp` with a wildcard (`*.txt`) to copy all `.txt` files into `txt_backups/`.

### Exercise 18: Safe vs. Force Folder Deletion (`rmdir` vs `rm -r`)

* **Scenario:** Inside your `music` folder, `music/electronic` is completely empty, while `music/rock` has files inside it.
* **Challenge:**
  1. Delete `music/electronic` using `rmdir` (the safe command that only deletes empty folders).
  2. Delete `music/rock` and everything inside it using `rm -r`.

### Exercise 19: Making a Quick Welcome Script (`chmod +x`)

* **Scenario:** Let's build a mini Bash script that prints `"Welcome to the Arena!"` and shows the top 2 players from `squad_kills.txt`.
* **Challenge:**
  1. Run `echo "#!/bin/bash" > welcome.sh`
  2. Run `echo "echo 'Welcome to the Arena!'" >> welcome.sh`
  3. Run `echo "sort -nr squad_kills.txt | head -n 2" >> welcome.sh`
  4. Use `chmod +x` to make `welcome.sh` executable, and run it with `./welcome.sh`!

### Exercise 20: The Windows PowerShell Check

* **Scenario:** Your friend is on Windows PowerShell (without WSL) and wants to read `chat.log` right inside their terminal, and then delete `movies.txt`.
* **Challenge:** Write the two official Windows PowerShell commands for:
  1. Reading `chat.log` (the PowerShell equivalent of `cat chat.log`)
  2. Deleting `movies.txt` (the PowerShell equivalent of `rm movies.txt`)
