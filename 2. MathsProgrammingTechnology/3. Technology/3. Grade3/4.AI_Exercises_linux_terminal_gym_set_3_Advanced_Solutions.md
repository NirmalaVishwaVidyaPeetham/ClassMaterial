## Part 1: Slicing & Transforming Data (`cut`, `tr`, `sed`)

### Exercise 1 Solution: Column Surgery (`cut`)

```bash
cut -d ',' -f 2,3 users.csv
```

* **Expected Output:**
  
  ```text
  username,role
  neo,admin
  trinity,admin
  morpheus,mod
  cypher,guest
  smith,admin
  ```
* **Why it works:** `-d ','` tells `cut` that columns are separated by commas, and `-f 2,3` extracts only the 2nd and 3rd columns.

### Exercise 2 Solution: Extracting & Sorting Admin Levels

```bash
grep "admin" users.csv | cut -d ',' -f 2 | sort
```

* **Expected Output:**
  
  ```text
  neo
  smith
  trinity
  ```
* **Why it works:** `grep` narrows the rows down to admins, `cut` isolates just the username column, and `sort` puts them in alphabetical order.

### Exercise 3 Solution: ALL CAPS HYPE (`tr`)

```bash
cat users.csv | tr 'a-z' 'A-Z' | tr ',' ' '
```

* **Expected Output:**
  
  ```text
  ID USERNAME ROLE LEVEL
  1 NEO ADMIN 99
  2 TRINITY ADMIN 95
  3 MORPHEUS MOD 88
  4 CYPHER GUEST 12
  5 SMITH ADMIN 100
  ```
* **Why it works:** The first `tr` translates all lowercase letters to uppercase, and the second `tr` swaps every comma with a space.

### Exercise 4 Solution: Live Stream Redaction (`sed`)

```bash
sed 's/admin/REDACTED/g' users.csv
```

* **Expected Output:** Every instance of `admin` is printed as `REDACTED` on your screen, while `users.csv` on disk remains untouched.

### Exercise 5 Solution: In-Place Config Patching (`sed -i`)

```bash
cp app.conf app.conf.bak
sed -i 's/debug/production/g' app.conf
sed -i 's/offline/online/g' app.conf
```

* **Why it works:** The `-i` flag tells `sed` to edit the file **in-place** (saving the changes directly to disk instead of just printing them).

### Exercise 6 Solution: Auditing Your Config Changes (`diff`)

```bash
diff -u app.conf.bak app.conf
```

* **Expected Output:**
  
  ```diff
  --- app.conf.bak
  +++ app.conf
  @@ -1,4 +1,4 @@
   server_ip=192.168.1.10
   port=8080
  -mode=debug
  -status=offline
  +mode=production
  +status=online
  ```
* **Why it works:** `diff -u` creates a unified diff (the exact same format GitHub uses for code commits!) showing removed lines with `-` and added lines with `+`.

## Part 2: Portals, T-Splitters, & Black Holes (`ln`, `tee`, `/dev/null`)

### Exercise 7 Solution: Creating a Shortcut Portal (`ln -s`)

```bash
mkdir -p config/production/v1
mv app.conf config/production/v1/
ln -s config/production/v1/app.conf quick_conf
cat quick_conf
```

* **Why it works:** `ln -s [target] [shortcut_name]` creates a symbolic link. When you run `ls -la`, you'll see `quick_conf -> config/production/v1/app.conf`.

### Exercise 8 Solution: Splitting the Stream (`tee`)

```bash
grep "admin" users.csv | tee admins_only.csv
```

* **Why it works:** Unlike `>`, which hides the output inside the file, `tee` prints the matching lines right onto your terminal AND writes them to `admins_only.csv`.

### Exercise 9 Solution: Dynamic File Naming (`$(...)`)

```bash
cp users.csv users_backup_$(whoami).csv
```

* **Why it works:** Bash evaluates `$(whoami)` first (e.g., `ubuntu` or `runner`), turns the filename into `users_backup_ubuntu.csv`, and then runs the `cp` command.

### Exercise 10 Solution: Silencing the Noise (`2> /dev/null`)

```bash
cat users.csv ghost_file.txt 2> /dev/null
```

* **Why it works:** Standard Output (channel `1`) prints `users.csv` to the screen normally, while Standard Error (channel `2`, where the `No such file or directory` message lives) gets routed straight into `/dev/null` and disappears.

## Part 3: Archiving, Compression, & Disk Forensics (`tar`, `du`, `find`)

### Exercise 11 Solution: Packing the Vault (`tar -czvf`)

```bash
tar -czvf config_backup.tar.gz config/
```

* **Why it works:** `-c` creates a new archive, `-z` compresses it using gzip, `-v` lists the files being packed, and `-f` specifies the archive filename.

### Exercise 12 Solution: Extracting the Vault in a Clean Room (`tar -xzvf`)

```bash
mkdir restore_test
tar -xzvf config_backup.tar.gz -C restore_test
find restore_test
```

* **Why it works:** `-x` switches `tar` from "create mode" to "extract mode," and `-C restore_test` unpacks the archive cleanly inside `restore_test/`.

### Exercise 13 Solution: Checking Folder Weight (`du -sh`)

```bash
du -sh .
du -sh *
```

* **Why it works:** `-s` summarizes each item instead of listing every single nested sub-file, and `-h` formats the byte counts into human-readable units like `4.0K` or `12M`.

### Exercise 14 Solution: Mass File Spawning & Batch Renaming Loop

```bash
mkdir -p logs && touch logs/log_{1..5}.txt
ls logs
```

* **Expected Output:** `log_1.txt  log_2.txt  log_3.txt  log_4.txt  log_5.txt`
* **Why it works:** `{1..5}` automatically expands into `logs/log_1.txt logs/log_2.txt ...` before `touch` even runs!

### Exercise 15 Solution: Finding Empty Files (`find -empty`)

```bash
find . -type f -empty
```

* **Expected Output:** Lists `./logs/log_1.txt` through `./logs/log_5.txt`.
* **Bonus Pro-Tip:** If you ever want to delete all empty files in one shot, you can run `find . -type f -empty -delete`!

## Part 4: Advanced Scripting, Env Variables, & Multi-Stage Boss Pipelines

### Exercise 16 Solution: Custom Environment Variables (`export`)

```bash
export PLAYER_NAME="MasterChief"
export LEVEL=99
echo "Player $PLAYER_NAME has reached level $LEVEL!" > player_card.txt
cat player_card.txt
```

* **Expected Output:** `Player MasterChief has reached level 99!`

### Exercise 17 Solution: Skipping the Header Line (`tail -n +2`)

```bash
tail -n +2 users.csv | wc -l
```

* **Expected Output:** `5`
* **Why it works:** `users.csv` has 6 lines total, so `tail -n +2` starts outputting at line 2, stripping off the column titles so `wc -l` counts only data rows.

### Exercise 18 Solution: The Role Frequency Counter (`cut` + `sort` + `uniq -c`)

```bash
tail -n +2 users.csv | cut -d ',' -f 3 | sort | uniq -c | sort -nr
```

* **Expected Output:**
  
  ```text
        3 admin
        1 mod
        1 guest
  ```
* **Why it works:** This classic data-science pipeline strips the header, grabs column 3 (`role`), groups identical roles together (`sort`), counts how many times each role appears (`uniq -c`), and sorts the counts from highest to lowest (`sort -nr`).

### Exercise 19 Solution: Automated Cleanup Script with Arguments (`$1`)

```bash
printf "#!/bin/bash\necho \"Hello \$1, welcome to $(hostname)!\"\n" > greeter.sh
chmod +x greeter.sh
./greeter.sh CyberNinja
```

* **Expected Output:** `Hello CyberNinja, welcome to [your_computer_name]!`
* **Why it works:** Inside a Bash script, `$1` automatically grabs the first word passed after the script name (`CyberNinja`).

### Exercise 20 Solution: The Ultimate Data Engineering Boss Pipeline

```bash
tail -n +2 users.csv | grep -v "guest" | cut -d ',' -f 2,4 | tr ',' ':' | tr 'a-z' 'A-Z' | tee elite_roster.txt
```

* **Expected Output (both on screen and inside `elite_roster.txt`):**
  
  ```text
  NEO:99
  TRINITY:95
  MORPHEUS:88
  SMITH:100
  ```
* **Why it works:** Every stage in the pipeline transforms the stream of text step-by-step:
  1. `tail -n +2` drops the header row.
  2. `grep -v "guest"` removes Cypher's row.
  3. `cut -d ',' -f 2,4` keeps only `username,level`.
  4. `tr ',' ':'` turns commas into colons.
  5. `tr 'a-z' 'A-Z'` capitalizes the names.
  6. `tee elite_roster.txt` displays the final leaderboard and saves it to disk!
