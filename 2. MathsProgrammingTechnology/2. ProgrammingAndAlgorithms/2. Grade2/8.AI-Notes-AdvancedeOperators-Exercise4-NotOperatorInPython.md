Python Bitwise NOT (`~10`) & Two's Complement Notes
---------------------------------------------------

* * *

📝 Overview
-----------

In Python, the bitwise NOT operator (`~`) performs a bitwise inversion on integers. When you run `~10`, the result is `-11`. This outcome is a direct consequence of how computers store negative integers using a system called Two's Complement.

* * *

🧮 The Fast Formula
-------------------

You can skip binary conversion entirely by using this built-in mathematical rule:  
$$\sim x = -x - 1$$

* Example: $\sim 10 = -10 - 1 = \mathbf{-11}$
* Example: $\sim(-5) = -(-5) - 1 = 5 - 1 = \mathbf{4}$

* * *

⚙️ Step-by-Step Breakdown (Using 8-Bit Binary)
----------------------------------------------

Step 1: Represent `10` in Binary
--------------------------------

Write the number 10 as an 8-bit positive integer.

* Binary: `0000 1010` (calculated as 8 + 2 = 10)

Step 2: Apply the Bitwise NOT (`~`)
-----------------------------------

Flip every single bit. Every `0` turns into a `1`, and every `1` turns into a `0`.

* Flipped Binary: `1111 0101`

Step 3: Interpret via Two's Complement
--------------------------------------

Because the leftmost bit (the Sign Bit) is a `1`, the computer reads this as a negative number. In an 8-bit signed system, the leftmost position has a value of -128.

| Bit Position | 7 (Sign Bit) | 6   | 5   | 4   | 3   | 2   | 1   | 0   |
| ------------ | ------------ | --- | --- | --- | --- | --- | --- | --- |
| Place Value  | -128         | +64 | +32 | +16 | +8  | +4  | +2  | +1  |
| Flipped Bits | 1            | 1   | 1   | 1   | 0   | 1   | 0   | 1   |

Add up all the active values (1s):  
$$\text{Value} = -128 + 64 + 32 + 16 + 4 + 1 = \mathbf{-11}$$

* * *

🧠 Understanding Two's Complement
---------------------------------

Two's complement is the standard binary encoding system used by modern computers to store and compute signed (positive and negative) integers.
Why do computers use it?

------------------------

* Unified Hardware: It eliminates the need for separate computer circuits for subtraction. To subtract A - B, the computer simply calculates A + (-B).
* Single Zero: Older systems had a "positive zero" and a "negative zero". Two's complement gives a unique binary representation for `0` (`0000 0000`).

How to manually find a negative number's value
----------------------------------------------

If you see a negative binary number like `1111 0101` and want to find what it represents without using place-value math, use the Two's Complement Trick:

1. Flip all bits: `1111 0101` becomes `0000 1010`
2. Add 1: `0000 1010` + `1` = `0000 1011` (which is 11 in decimal)
3. Add a negative sign: The result is -11

* * *

⚠️ Python Specific Note: Infinite Bit Width
-------------------------------------------

In low-level languages like C or Java, integers have fixed sizes (e.g., 8-bit, 32-bit). If you flip the bits, you see the exact bits in memory.

Python integers have arbitrary precision (infinite bit width). Python simulates an infinite chain of `0`s in front of positive numbers, and an infinite chain of `1`s in front of negative numbers. This is why Python relies heavily on the formula ~ x = -x - 1 to ensure bitwise NOT calculations stay consistent no matter how large the number grows.
