Everything You Need to Know About Sets (Without Falling Asleep)

A complete breakdown of the class notes with visual analogies, step-by-step proofs, and an interactive quiz at the bottom.

1

What Actually Is a Set?

A set is simply a well-defined collection of distinct objects—like a Spotify playlist, a group chat, or your sneaker collection. We wrap the items (called elements) inside curly brackets:

Streaming = {Netflix, Disney+, YouTube}
  • Order doesn't matter: {Netflix, Disney+, YouTube} is the exact same set as {YouTube, Netflix, Disney+}.
  • No repeats allowed: Listing an item twice still only counts once! {1, 2, 2, 3} automatically simplifies to {1, 2, 3}.
2

Venn Diagrams: Visualizing the Drama

If sets are friend groups at school, a Venn diagram is the social map showing who hangs out where inside the Universal Set (U) box:

Set A (Video Games) = {Alex, Sam, Jordan, Taylor}
Set B (Basketball) = {Jordan, Taylor, Morgan, Casey}

The left circle holds gamers, the right circle holds basketball players, and the football-shaped lens in the middle is where Jordan and Taylor live because they do both!

3

The Big Three Core Set Operations

A. Intersection (A ∩ B) — The “Both” Zone: Symbol ∩ looks like a bridge or an n in intersection. Only elements in both sets: {Jordan, Taylor}.
B. Union (A ∪ B) — The “All Together” Vibe: Symbol ∪ looks like a giant cup holding everything from either set: {Alex, Sam, Jordan, Taylor, Morgan, Casey}.
C. Complement (A′ or Ac) — The “Anti-You”: Everything inside the Universal Set U that is not in A. If 100 kids are in your grade (U) and 15 are in Math Club (A), then A′ is the other 85 kids!
4

Set Difference (A − B)

In A − B (“A minus B”), you start with everything in Set A, and if any of those elements are also hanging out in Set B, you kick them out!

A = {1, 2, 3, 4, 5}
B = {4, 5, 6, 7}
A − B = {1, 2, 3} (Strictly A!)

Notice that 6 and 7 in B don't matter at all for A − B because we only care about what gets removed from A.

5

Why Does A − B = A − (A ∩ B)?

  1. What is A ∩ B? It's the overlapping middle lens where A and B share elements ({4, 5}).
  2. What does A − (A ∩ B) mean? Start with the whole circle A ({1, 2, 3, 4, 5}) and chop off the overlapping middle ({4, 5}).
  3. What's left over? The exact same crescent “moon-shaped” slice of A ({1, 2, 3}) that doesn't touch B!
6

De Morgan's Laws & Pocket Rules

  • De Morgan's Laws (The Plot Twists):
    (A ∪ B)′ = A′ ∩ B′ and (A ∩ B)′ = A′ ∪ B′
    Flipping a combined set inside-out swaps ∪ and ∩!
  • Commutative Property: Order doesn't change unions or intersections: A ∪ B = B ∪ A and A ∩ B = B ∩ A.
  • Idempotent Laws: Combining a set with itself changes nothing: A ∪ A = A and A ∩ A = A.
