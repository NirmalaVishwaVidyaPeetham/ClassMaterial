### Page 29 (Textbook Page 171)

**యుద్ధ కాండ** (యుద్ధ విభాగం / The Chapter of War)

శ్రీరాముడు (రాముడు / Lord Rama) హనుమంతుడి (హనుమంతుని యొక్క / Hanuman's) సాహసాన్ని (ధైర్యసాహసాలను / bravery) ప్రశంసించాడు (మెచ్చుకున్నాడు / praised). గరుత్మంతుడికి (గరుడ పక్షికి / to Garuda), వాయుదేవుడికి (గాలి దేవునికి / to the Wind God Vayu), హనుమంతుడికి (ఆంజనేయునికి / to Hanuman) తప్ప (కాకుండా / except) ఈ (ఈ / this) మహాసముద్రాన్ని (పెద్ద కడలిని / great ocean) లంఘించడానికి (దాటడానికి / to cross over) ఇతరులకు (వేరే వారికి / to others) సాధ్యం (వీలు / possible) కాదన్నాడు (కాదని చెప్పాడు / said it is not). ఇచ్చిన (అప్పగించిన / given) పనిని (కార్యాన్ని / task) సాధించడమేగాక (పూర్తి చేయడమే కాకుండా / not only accomplishing), దానికి (ఆ పనికి / to that) భంగం (ఆటంకం / harm or hindrance) కలగకుండా (ఏర్పడకుండా / without happening) దానికనుబంధమైన (దానికి సంబంధించిన / connected to it) ఇతర (వేరే / other) కార్యాలను (పనులను / tasks) సాధించేవాడు (పూర్తిచేసేవాడు / one who accomplishes) ఉత్తముడైన (శ్రేష్ఠుడైన / the best) సేవకుడు (బంటు / servant). కేవలం (మాత్రమే / merely) ఇచ్చిన (చెప్పిన / assigned) పనినే (కార్యాన్నే / task itself) నెరవేర్చేవాడు (పూర్తిచేసేవాడు / one who fulfills) మధ్యముడు (సాధారణమైనవాడు / mediocre or average). తనకు (తన వద్ద / to oneself) సామర్థ్యం (శక్తి / capability) ఉన్నా (ఉన్నప్పటికీ / even though having) ఇచ్చిన (అప్పగించిన / assigned) పనిని (కార్యాన్ని / work) పూర్తిచేయనివాడు (ముగించనివాడు / one who does not complete) అధముడు (తక్కువ స్థాయివాడు / the lowest or inferior). సీతాదేవి (సీతమ్మ యొక్క / Sita Devi's) కుశల వార్త (క్షేమ సమాచారం / news of well-being) చెప్పి (తెలియజేసి / having told) మహోపకారం (గొప్ప మేలు / great help) చేసిన (ఆచరించిన / who did) హనుమంతునకు (హనుమంతునికి / to Hanuman) ఏమియ్యగలనంటూ (ఏమి ఇవ్వగలను అని అంటూ / saying what can I give) దగ్గరకు (చెంతకు / close) తీసుకొని (చేర్చుకొని / taking) గట్టిగా (బలంగా / tightly) గుండెకు (రొమ్ముకు / to the chest) హత్తుకున్నాడు (కౌగిలించుకున్నాడు / hugged) శ్రీరాముడు (రాముడు / Lord Rama). ఇదే (ఇది మాత్రమే / this alone) తానియ్యగల (తాను ఇవ్వగలిగిన / that he can give) సర్వస్వమన్నాడు (సమస్త సంపద అని అన్నాడు / said is his everything). ఆదరాభిమానాలకు (ప్రేమానురాగాలకు / to affection and respect) మించిన (ఎక్కువైన / greater than) ఆస్తి (సంపద / wealth) ఉండదు (లేదు / does not exist) కదా! (కదా / isn't it!)

శ్రీరాముడి (రాముని యొక్క / Rama's) మనసులో (హృదయంలో / in the mind) మళ్ళీ (తిరిగి / again) దుఃఖం (బాధ / sorrow) పొంగిపొర్లింది (ఉప్పొంగింది / welled up). సుగ్రీవుడు (వానరరాజు సుగ్రీవుడు / Sugriva) ఊరడించాడు (ఓదార్చాడు / consoled). నిరుత్సాహం (ఉత్సాహం లేకపోవడం / discouragement) ప్రయోజనాలను (లాభాలను / benefits or goals) నాశనం (పాడు / destroy) చేస్తుందన్నాడు (చేస్తుందని చెప్పాడు / said it does). దుఃఖం (విచారం / sorrow) శౌర్య పరాక్రమాలను (వీరత్వాన్ని, బలాన్ని / valor and prowess) దిగజారుస్తుందన్నాడు (తగ్గిస్తుందని అన్నాడు / said it diminishes). శత్రువు (విరోధి / enemy) విషయంలో (గురించి / regarding) ఇప్పుడు (ఈ సమయంలో / now) దుఃఖం (బాధ / grief) కాదు (కాదు / not), క్రోధం (కోపం / anger) చూపవలసిన (ప్రదర్శించాల్సిన / that needs to be shown) సమయమని (వేళ అని / time that) సూచించాడు (సలహా ఇచ్చాడు / suggested). మహాసముద్రంమీద (పెద్ద కడలి పైన / over the great ocean) సేతువును (వంతెనను / bridge) కట్టకుండా (నిర్మించకుండా / without building) లంకను (లంకా నగరాన్ని / Lanka) జయించడం (గెలవడం / conquering) ఇంద్రాది దేవతలకు (ఇంద్రుడు మొదలైన దేవతలకు / to Indra and other gods) కూడా (సైతం / even) సాధ్యం (వీలు / possible) కానిపని (చేయలేని పని / impossible task) అన్నాడు (చెప్పాడు / said). శ్రీరాముడు (రాముడు / Rama) అడగగా (ప్రశ్నించగా / upon asking) హనుమంతుడు (ఆంజనేయుడు / Hanuman) లంకానగరంలోని (లంకలోని / inside the city of Lanka) రక్షణ వ్యవస్థను (కాపలా ఏర్పాటును / defense system) గురించి (విషయమై / about) వివరంగా (పూర్తిగా / in detail) చెప్పాడు (తెలిపాడు / told).

మధ్యాహ్నమైంది (మిట్టమధ్యాహ్న సమయం అయింది / it became midday). ఈ (ఈ / this) విజయ ముహూర్తమే (గెలుపును ఇచ్చే శుభ సమయమే / auspicious moment of victory) ప్రయాణానికి (బయలుదేరడానికి / for the journey) తగినదని (సరైనదని / is suitable) శ్రీరాముడు (రాముడు / Rama) సుగ్రీవునితో (సుగ్రీవుడితో / with Sugriva) అన్నాడు (పలికాడు / said). శ్రీరాముడు (రాముడు / Rama) వానరులతో (కోతుల సైన్యంతో / with the vanaras), 'నీలుడు (నీలుడు అనే వానర వీరుడు / Nila) సైన్యానికి (దళానికి / to the army) మార్గం (దారి / path) చూపుతూ (చూపిస్తూ / showing) ముందునడవాలి (అందరికంటే ముందు వెళ్ళాలి / should walk in front). లక్షలాది (లక్షల సంఖ్యలో ఉన్న / hundreds of thousands of) వానరులు (వానర వీరులు / vanaras) అతణ్ణి (నీలుడిని / him) అనుసరించాలి (వెంబడించాలి / should follow). వృద్ధులు (ముసలివారు / the elderly), బలహీనులు (శక్తి లేనివారు / the weak), బాలురు (చిన్నపిల్లలు / children) కిష్కింధలోనే (కిష్కింధ నగరంలోనే / in Kishkindha itself) ఉండాలి (నివసించాలి / should stay). సుగ్రీవా! వానరులు (కోతులు / vanaras) ‘జయజయ’ ధ్వానాలు (జయజయకారాలు, గెలుపు నినాదాలు / victory cheers) చేశారు (చేశెను / made). అవి (ఆ ధ్వానాలు / they) రావణుని (రావణాసురుని / Ravana's) గుండెలో (హృదయంలో / in the heart) 'అప' శబ్దాన్ని ('అప' అనే అక్షరాలను - అంటే అపజయం అని / the prefix 'apa' meaning defeat) జోడించుకొని (కలుపుకొని / adding) ప్రతిధ్వనిస్తున్నాయి (మారుమోగుతున్నాయి / are echoing). హనుమంతుని (ఆంజనేయుని / Hanuman's) చేతిలో (చేతి దెబ్బకు / at the hands of) ధూమ్రాక్షుడు (ఒక రాక్షస వీరుడు / Dhumraksha), అకంపనుడు (మరొక రాక్షసుడు / Akampana), అంగదుడి (అంగదుని / Angada's) బారినపడి (చేతిలో చిక్కి / falling prey to) వజ్రదంష్ట్రుడు (రాక్షస వీరుడు / Vajradamshtra), నీలుడికి (నీలుని చేతికి / to Nila) చిక్కి (దొరికి / caught by) ప్రహస్తుడు (రావణుని సేనాని / Prahasta) యమపురిబాట (మరణ మార్గం / path to the abode of Yama/death) పట్టారు (వెళ్ళారు / took/died).

రావణుని (రావణాసురుని / Ravana's) బాణశక్తికి (బాణాల దెబ్బకు / to the power of arrows) సుగ్రీవుడు (సుగ్రీవుడు / Sugriva) మూర్ఛపోయాడు (స్పృహతప్పాడు / fainted). శ్రీరాముడు (రాముడు / Rama) విల్లందుకున్నాడు (ధనుస్సును చేతబట్టాడు / took up the bow). అన్నను (శ్రీరాముడిని / elder brother) వారించి (ఆపి / stopping) లక్ష్మణుడు (లక్ష్మణుడు / Lakshmana) రావణుణ్ణి (రావణాసురుడిని / Ravana) ఎదిరించడానికి (ఎదుర్కోవడానికి / to confront) పూనుకున్నాడు (సిద్ధపడ్డాడు / undertook). వానరసేనమీద (వానర సైన్యం పైన / upon the vanara army) శరవర్షధారకురిపిస్తున్నాడు (బాణాల వర్షం కురిపిస్తున్నాడు / is showering a rain of arrows) రావణుడు (రావణాసురుడు / Ravana). ఆంజనేయుడు (హనుమంతుడు / Hanuman) రావణుడి (రావణుని / Ravana's) ధాటికి (వేగానికి, దాడికి / to the onslaught) అడ్డుకట్ట (అడ్డు / barrier) వేశాడు (వేసెను / put). అరచేతితో (చేతితో / with the palm) హనుమంతుణ్ణి (హనుమంతుడిని / Hanuman) బలంగా (గట్టిగా / forcefully) చరిచాడు (కొట్టాడు / slapped/struck) రావణుడు (రావణాసురుడు / Ravana). మారుతి (హనుమంతుడు / Maruti) చలించిపోయాడు (కంపించాడు / shook/staggered). అయినా (అయినప్పటికీ / yet) క్షణంలో (తక్షణమే / in a moment) తేరుకున్నాడు (నిలదొక్కుకున్నాడు / recovered). అరచేతితో (తన అరచేతితో / with his palm) రావణుణ్ణి (రావణాసురుడిని / Ravana) ఒక్క (ఒకే ఒక / one single) దెబ్బ (దెబ్బను / blow) వేశాడు (కొట్టాడు / struck). దశగ్రీవుడు (పది తలల రావణుడు / ten-necked Ravana) కంపించిపోయాడు (వణికిపోయాడు / trembled). తేరుకుని (కోలుకుని / recovering) 'వానరా! (ఓ వానరుడా / O Vanara!) భళా (శభాష్ / bravo), నాకు (నాకు / to me) శత్రువువే (విరోధివే / an enemy) అయినా (అయినప్పటికీ / even though) నీ (నీ యొక్క / your) శక్తిని (బలాన్ని / strength) మెచ్చుకుంటున్నా'నని (ప్రశంసిస్తున్నాను అని / that I appreciate) యుద్ధ స్ఫూర్తిని (యుద్ధ ధర్మాన్ని / sportsman/warrior spirit) చాటాడు (ప్రదర్శించాడు / showed) రావణుడు (రావణాసురుడు / Ravana).

Lakshmana's) ఎదలో (రొమ్ములో / in the chest) నాటుకుంది (గుచ్చుకుంది / pierced/embedded). స్పృహదప్పాడు (మూర్ఛపోయాడు / lost consciousness) లక్ష్మణుడు (లక్ష్మణుడు / Lakshmana). అతన్ని (లక్ష్మణుడిని / him) (లక్ష్మణుడిని / Lakshmana) శ్రీరాముని (రాముని / Sri Rama's) వద్దకు (దగ్గరికి / to) చేర్చాడు (తీసుకెళ్ళాడు / brought). హనుమంతుని (హనుమంతుడి యొక్క / Hanuman's) కోరిక (అభ్యర్థన / wish/request) మేరకు శత్రుపక్షాన్ని (విరోధుల సైన్యాన్ని / the enemy side) మానసికంగా (మనసు పరంగా / psychologically/mentally) దెబ్బతీయదలచాడు (బలహీనపరచాలని అనుకున్నాడు / wanted to strike/weaken) ఇంద్రజిత్తు (ఇంద్రజిత్తు / Indrajit). హనుమదాది (హనుమంతుడు మొదలైన / Hanuman and other) వానరవీరులు (వానర యోధులు / vanara warriors) చూస్తుండగా (గమనిస్తుండగా / while watching) మాయాసీతను (మాయతో సృష్టించిన సీత బొమ్మను / illusory Sita) సంహరించాడు (నరికి చంపాడు / killed). అందరూ (చూసిన వారంతా / everyone) నిజమేననుకున్నారు (నిజంగానే సీత చనిపోయిందని అనుకున్నారు / thought it was real). ఈ (ఈ / this) వార్త (విషయం / news) తెలిసి (విని / knowing) శ్రీరాముడు (రాముడు / Rama) శోకసంద్రంలో (దుఃఖ సముద్రంలో / in an ocean of grief) మునిగిపోయారు (మునిగిపోయాడు / sank/plunged). ఇదంతా (ఈ కనిపించిందంతా / all this) ఇంద్రజిత్తు (ఇంద్రజిత్తు యొక్క / Indrajit's) మాయేనని (మోసమే అని / is just an illusion) విభీషణుడు (విభీషణుడు / Vibhishana) తెలపడంతో (చెప్పడంతో / by informing) అందరూ (అక్కడున్న వారంతా / everyone) ఊపిరిపీల్చుకున్నారు (నిశ్చింతపడ్డారు / breathed a sigh of relief).
